# Narrated audio (outbound)

Claudine's Walking Through episodes as MP3s (Sonia voice), for downloading to a phone and listening offline.
Pull the repo and copy from here. These files are delivery hand-offs, not site content: `functions/outbound/`
returns 404 for everything under `/outbound/` on the live site.

- `walking-through-*.mp3`: one file per Walking Through essay or episode, named after its MD in `docs/`
- `actually-reading-the-manual/NN-*.mp3`: one file per episode, named after its MD in `docs/actually-reading-the-manual/`
