# StG 44 (2044) gunsmith bench (copy)

A hosted copy of the Partisan Project's StG 44 gunsmith bench with all four rebuilds (Magnific · Tripo P2 A and B,
Claude Opus A · LLM-Rebuild, Claude Opus B · Neuro-Bash). The source of truth is `VincentDN/partisan-project`
(`workbench/stg44/`); this folder mirrors only the files the bench loads, at the same relative paths, so its code runs
unchanged. Entry: `/3d/stg44-workbench/` (forwards to `workbench/stg44/`).

Copied from partisan-project at commit 7d4eff2 on 21 November 2026. The only edits are in
`workbench/stg44/index.html`: the back link points to `/projects/3d/`, and the title, canonical and favicon are the
site's. To refresh, record what the bench requests in a browser while cycling every rebuild and option, copy those files
and `assets/audio/foley/` again, and reapply those edits.
