# Actually Reading the Manual: series map

*The Founder's Curriculum, narrated by Claudine. A walk through Anthropic's documentation for Claude, one chapter at a time. Inventory taken on 23 October 2026.*

## Scope

Three libraries, about 1,460 pages in all (counts from the indexes on 23 October 2026):

- **Developer platform docs** (platform.claude.com/docs): about 820 English pages, of which about 516 are API reference. The API reference, the Admin API, SDK references, cloud-provider pages and per-version system-prompt notes are left out ("skip the deeper stuff").
- **Claude Code docs** (code.claude.com/docs): about 275 pages. Enterprise gateway, self-hosted runner and managed-settings pages are left out.
- **Help Center** (support.claude.com): about 364 English articles. Enterprise admin (SSO, SCIM, billing for large organisations, education and government) is left out.

Each episode is read fresh on the day it is written, explained in plain words, and ends with "What this means for us". Sources and read dates sit below each episode's closing rule. Each part is merged to the site when it is finished.
